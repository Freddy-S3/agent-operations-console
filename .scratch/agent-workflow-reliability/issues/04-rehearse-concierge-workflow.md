# Rehearse the concierge workflow

Status: draft.

## Delivery

Demonstrate the proposed service on a synthetic repository before exposing it to a prospective client.

## Acceptance criteria

- One operator can start and supervise one agent-assisted repository workflow.
- The workflow includes one explicit human approval gate.
- The workflow produces a durable evidence bundle containing the plan, changes, checks, review result, and approval history.
- A deliberately failed run can be recovered without losing the relevant context or creating an unsafe duplicate action.
- The operator can explain the workflow to a client using a short runbook or teaching guide.
- The rehearsal records the manual steps that should remain service work and the repeated steps that might later justify a UI.
