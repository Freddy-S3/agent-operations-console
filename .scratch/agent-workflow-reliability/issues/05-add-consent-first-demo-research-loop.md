# Add a consent-first free-demo research loop

Status: draft.

## Delivery

Define and, if justified, add privacy-preserving telemetry to the free public demo so usage can inform product research without treating visitors as an unconsenting data source.

## Acceptance criteria

- The research questions are written before selecting events to collect.
- The default data is limited to aggregate or pseudonymous interaction events such as demo start, workflow step reached, approval interaction, recovery interaction, and contact action.
- Prompts, source code, repository contents, credentials, run logs, uploaded files, and free-form user text are not collected by default.
- The site clearly explains optional analytics or research collection and provides an opt-out path where applicable.
- Retention, access, deletion, and data minimization rules are documented.
- Any direct research invitation is separate from the demo experience and does not imply that usage creates a customer relationship.
- Findings are used to generate interview hypotheses and product questions, not to claim willingness to pay.
- The demo still works when optional telemetry is disabled.

## Blocked by

Tasks 3 and 4: Publish the minimal credibility website and Rehearse the concierge workflow.

## Notes

This ticket is for a free public demo, not for silently harvesting client code or private pilot data.
