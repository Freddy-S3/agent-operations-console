# Specify the first UI slice after the paid pilot

Status: draft.

## Delivery

Translate repeated manual work from the first paid pilot into one narrow Agent Operations Console UI slice.

## Acceptance criteria

- The pilot evidence shows repeated manual work that a UI could remove or make safer.
- The slice names one operator role, one repository workflow, and one primary interaction.
- The slice prioritizes supervision, approval, evidence, or recovery instead of generic workflow authoring.
- The slice includes the teaching and handoff experience needed for a small team to operate it.
- The design records which provider, repository, and harness boundaries remain outside the product.
- A baseline metric and a demoable success condition are defined before implementation begins.
- The decision is explicitly build, continue concierge-only, revise, or stop.

## Blocked by

Task 6: Run discovery and secure the first paid pilot.

## Notes

This ticket intentionally comes after paid evidence so the UI reflects a repeated customer workflow rather than our preferred architecture.
